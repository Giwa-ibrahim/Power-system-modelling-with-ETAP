# Modelling of Short circuit fault analysis with ETAP Software
This shows the design and simulation of a simple one-line diagram with fault scenarios at Bus 1 and Bus 2.

For more understanding, the symmetrical fault analysis only deals with the 3-phase fault with and without ground scenarios (LLL or LLL-G), while the Unsymmetrical fault; majorly the Shunt fault type are Single line to ground (L-G), Double line (L-L) and Double line to ground (LL-G).
